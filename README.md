# AppSorter
앱 종류, 아이콘 색깔별로 어플을 분류하는 앱

### 카테고리별 분류 방법
app info 의 category 정보를 활용하여 분류하고자 하였으나 <br/>
카테고리가 아예 분류되어 있지 않거나 분류되는 범위가 원하는 것과는 조금 달랐다.<br/>
할 수 없이 플레이스토어에서 각 카테고리별 상위 50개 앱을 직접 수집하여 DB를 만들었다.<br/>
그래서 약 700개 정도의 앱은 분류가 가능하지만 그 외의 앱은 분류가 되지 않는다.<br/>
추후 이 앱을 업데이트 할 때에는 gpt api를 사용하면 모든 앱의 분류가 가능해 질 것이다.<br/>

##### 업데이트시 변경 로직
1. 사용자별 저장된 앱을 기록하는 DB 생성
2. 기존에 저장된 앱 외 새로운 앱 설치 발견시 gpt에 분류 요청
3. 분류된 앱을 다시 DB에 저장 후 저장된 분류대로 앱에 표시
